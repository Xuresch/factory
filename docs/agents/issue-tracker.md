# Issue tracker: Local Markdown

Tickets live in `.scratch/<feature>/issues/NN-<slug>.md` in this repo, addressed as `<feature>/<NN>`. A ticket's state is its `Status:` line, using the triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`, `done`); `Blocked by:` names the tickets that gate it, and comments go under `## Comments`.

GitHub issues are disabled for this repo. Pull requests on GitHub are still used for work done by hand; the factory merges its jobs into `main` locally.
